# «Витрина» — свой лаунчер проекта

Светлый домашний экран в стиле Apple TV: часы и дата, большая карточка
погоды, ряд приложений на матовой панели, а ниже — ярлыки и курсы. Работает на приставке Xiaomi TV Box S 2
(Android 14) и рассчитан на Mi TV 4S (Android 9), на ТВ ещё не проверялся.

## Что на экране

- **Погода.** Слева — сейчас: температура, описание, от и до за ближайшие
  сутки, восход и закат. Справа — 8 часов вперёд и 4 следующих дня.
- **Ряд приложений.** OK — открыть. Удержать OK (или кнопка ☰) — сдвинуть
  влево/вправо или убрать. Добавить — в «Все приложения».
- **Ниже ряда** (кнопка «вниз»): ярлыки «Все приложения», «Настройки»,
  «Wi-Fi», «Аксессуары» — меню «Пульты и аксессуары»: сопряжённые
  устройства (OK — их системные настройки: переименовать, отключить,
  забыть) и «Подключить новое» (поиск). Нужно разрешение «Устройства
  поблизости» — его выдаёт `08`, иначе лаунчер спросит сам; на телевизоре ещё входы HDMI. Курсы: доллар, евро,
  юань по ЦБ, биткоин и эфир, с изменением за сутки.
- **Слева вверху** — часы и дата. **Справа** — Wi-Fi, тема и настройки,
  под ними курсы коротко.
- **Тема** (кнопка с полукругом): «Авто» — тёмная с 19:00 до 9:00, светлая
  днём, переключается сама; или всегда светлая, или всегда тёмная.

## Откуда данные

Лаунчеру нужен интернет — только для этих адресов, больше никуда:

| Что | Откуда | Ключ |
|---|---|---|
| Погода | api.met.no (Норвежский метеоинститут) | не нужен |
| Курсы валют | cbr-xml-daily.ru (данные ЦБ РФ) | не нужен |
| Криптовалюты | api.coingecko.com | не нужен |

Open-Meteo из домашней сети приставки недоступен, поэтому погода с met.no.

## Город и ряд приложений

Файл `mibox-s2/vitrina.json` (пример — `launcher/vitrina.example.json`,
в git не попадает): `city`, `lat`, `lon` — город для погоды; `dock` — ряд
приложений. Если `dock` в файле нет, ряд остаётся таким, каким его
настроили пультом. После правки — `./mibox-s2/scripts/08-vitrina.sh`.

## Сборка и установка

```bash
# Один раз: Java 17 и Android SDK в ~/Android/Sdk (как для CleanYourTV)
echo "sdk.dir=$HOME/Android/Sdk" > launcher/local.properties
(cd launcher && ./gradlew assembleRelease)

./mibox-s2/scripts/08-vitrina.sh              # поставить и передать настройки
SET_HOME=1 ./mibox-s2/scripts/08-vitrina.sh   # и сделать домашним экраном
```

Зависимостей у приложения нет: весь код — в `app/src/main/java`,
около 1600 строк. APK подписан отладочным ключом ноутбука, поэтому
обновлять его можно только с этого же ноутбука.

## Откат

```bash
REMOVE_LAUNCHER=1 ./mibox-s2/scripts/99-restore.sh   # удалить и вернуть прежний дом
```

Только вернуть прежний домашний экран, не удаляя «Витрину»:

```bash
adb -s <ip>:5555 shell cmd package set-home-activity com.gathin.tvhome/.MainActivity
```
