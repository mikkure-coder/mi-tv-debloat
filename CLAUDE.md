# CLAUDE.md — инструкция агенту по проекту mi-tv-debloat

Этот файл читает агент (Claude Code) перед работой в репозитории. Здесь описано,
что это за проект, каких границ нельзя переходить, как устроен код и как
продолжать разработку.

---

## 1. Что это за проект

Набор bash-скриптов для «очистки» телевизора **Xiaomi Mi TV 4S 50"**
(Android TV 9/10, оболочка PatchWall): отключение рекламы, телеметрии и
предустановленного мусора + установка открытого лаунчера **FLauncher**
вместо PatchWall.

С 2026-10-25 в репозитории есть подпроект **`mibox-s2/`** — та же очистка для
приставки Xiaomi TV Box S 2 (Google TV). Его особенности и журнал — в
[`mibox-s2/CLAUDE.md`](mibox-s2/CLAUDE.md); правила этого файла действуют и там.

Владелец проекта **не программист**. Он запускает скрипты руками
с ноутбука, читает их комментарии и по ним понимает, что происходит.
Из этого следуют два правила, которые важнее красоты кода:

- **Каждый скрипт объясняет сам себя.** Шапка файла на русском: что делает,
  что меняет на ТВ, как запустить, как откатить. Внутри — комментарии перед
  каждым смысловым блоком, с объяснением *механизма*, а не пересказом строки.
- **Любое сообщение об ошибке — это инструкция, что делать.** Не
  `adb: error 3`, а «ТВ не ответил; проверь, что включена Отладка по сети,
  и что IP верный — посмотри в Настройки → Сеть».

## 2. Границы проекта — читать до первой правки

Слово «прошивка» в разговоре означает **только дебло́ат и смену лаунчера**.
В этом репозитории **запрещено**:

- разблокировка загрузчика, root, установка кастомных ROM, работа с recovery,
  запись в разделы через `dd`/`fastboot flash`;
- `pm uninstall --user 0` и любое другое **необратимое** удаление пакетов —
  только `pm disable-user --user 0`, которое откатывается через `pm enable`;
- отключение пакетов из [`packages/keep.txt`](packages/keep.txt) — это ядро
  Android, их отключение даёт бутлуп или «кирпич»;
- коммит в git IP телевизора, его MAC, логов запусков, бэкапов и `*.apk`
  (см. `.gitignore`; файл `.tv-host` локальный и в репозиторий не попадает);
- скачивание APK откуда-либо, кроме F-Droid / официальных исходников проекта.
  Разрешены три лаунчера:
  - FLauncher: `me.efesser.flauncher`, https://gitlab.com/flauncher/flauncher
    (готовый APK из F-Droid);
  - лаунчер CleanYourTV: `com.gathin.tvhome`, https://github.com/Gathin23/cleanyourtv
    (MIT), **только сборка из исходников** на ноутбуке, с конкретного
    просмотренного коммита (решение владельца 2026-10-25; код просмотрен на
    `204143007f0b`: нет разрешения INTERNET). Их `build-and-install.sh` и
    `tools/disable.sh` не запускать: установщик отключает Google-лаунчер и
    выдаёт `WRITE_SECURE_SETTINGS`. Службу специальных возможностей
    `HomeKeyService` не включать без отдельного решения — она нужна, только
    если кнопка Home шлёт `KEYCODE_ALL_APPS`. Ставить нашим `03`.
  - «Витрина»: `org.mitvdebloat.vitrina`, свой лаунчер проекта в `launcher/`
    (решение владельца 2026-10-25: «как в видео» — светлый экран, погода,
    курсы; полку фильмов Кинопоиска владелец в тот же день убрал, наверху
    вместо неё погода). Собирается здесь же, ставится `08`. В отличие
    от CleanYourTV у него есть `INTERNET` — только для api.met.no,
    cbr-xml-daily.ru и api.coingecko.com. Новые адреса и любые сторонние
    библиотеки — только с решения владельца. Город — в локальном
    `vitrina.json` папки устройства, в git его нет.
- отключение Google-лаунчера `com.google.android.tvlauncher` в обход условий.
  С 2026-10-25 (решение владельца) он не в стоп-листе, потому что иначе
  сторонний лаунчер на 4S не станет домом (приоритет HOME 2 против 0).
  Отключать — только строкой в `debloat.txt` через `02`, и только когда новый
  лаунчер установлен `03` и открылся ручным `am start`. Не трогать вместе с ним
  `com.android.tv.settings` (там `FallbackHome` — последняя страховка).

Любая операция, добавляемая в проект, должна иметь ответ на вопрос
**«как это откатить»**. Если ответа нет — операция в проект не входит.

## 3. Инварианты кода

Их нельзя сломать рефакторингом:

1. **Строгий режим.** Все скрипты начинаются с `source lib/common.sh`, который
   ставит `set -euo pipefail`. Не обходить его `|| true` без комментария,
   объясняющего, почему ошибка здесь безопасна.
2. **Адресация устройства.** Все команды к ТВ идут только через `adb_shell` /
   `adb_cmd` из `lib/common.sh` — они подставляют `-s "$TV_HOST:$TV_PORT"`.
   Голый `adb shell` ломается, когда к ноуту подключён ещё и телефон
   («more than one device»).
2а. **Папка устройства.** Всё, что своё у устройства, скрипты берут только
   через переменные из `lib/common.sh`: `PKG_DIR` (списки), `HOST_FILE`
   (`.tv-host`), `BACKUP_DIR`, `LOG_DIR`. Их корень — `DEVICE_DIR`: по
   умолчанию корень репозитория (телевизор), у приставки — `mibox-s2/`
   (задают её обёртки). Не писать `$ROOT_DIR/packages` и `$ROOT_DIR/.tv-host`
   напрямую — иначе приставка прочитает списки телевизора. Через `ROOT_DIR`
   идут только общие `apks/` и `themes/`.
3. **Стоп-лист.** `02-debloat.sh` до подключения к ТВ сверяет весь
   `debloat.txt` с `keep.txt` и встроенной `is_core_pkg` (ядро Android из
   CleanYourTV #884, `setupwraith`, `com.android.providers.*`). Совпадение —
   выход без единого отключения, переменной не обходится. Не ослаблять и не
   добавлять «FORCE»-обход. Единственное исключение (решение владельца
   2026-10-25): `setupwraith` на устройстве, у которого есть
   `packages/core-exceptions.txt` с этим именем, — сейчас только приставка.
   Список исключаемых имён зашит в `CORE_EXCEPTIONABLE`, его не расширять без
   отдельного решения владельца; 02 перед отключением мастера проверяет новый
   дом и владельца сети Wi-Fi.
3а. **Защита лаунчера.** `02-debloat.sh` обязан отказываться отключать
   `com.mitv.tvhome`, пока на ТВ не найден fallback-home (FLauncher,
   `com.google.android.tvlauncher` или `com.google.android.leanbacklauncher`).
   С 2026-10-24 проверка шире: список домашних экранов скрипт берёт у ТВ
   (`cmd package query-activities … category.HOME`) и не отключает ни один
   пакет из этого списка, а также `com.mitv.tvhome` / `com.mitv.tvhome.atv`,
   если после этого не останется другого дома. Причина: на живом 4S домом
   оказался Google tvlauncher, а PatchWall назывался `com.mitv.tvhome.atv`.
   С 2026-10-25 запасным домом не считается и `RecoveryActivity` мастера
   `com.google.android.tungsten.setupwraith`: на приставке TV Box S 2 он
   числится домом, но это аварийная заглушка (см. `mibox-s2/CLAUDE.md`).
   Эта проверка — главный предохранитель проекта, её не упрощать.
4. **DRY_RUN.** Любой скрипт, который что-то *меняет* на ТВ, поддерживает
   `DRY_RUN=1`: печатает команды и ничего не выполняет. Новый изменяющий
   скрипт без DRY_RUN не принимается.
5. **Откат.** Всё, что умеет делать `02`/`03`, должно уметь отменять `99`.
   Добавил новое действие — допиши обратное в `99-restore.sh`.
6. **Логи.** Пишем только через `log`/`warn`/`err` — они дублируют вывод
   в `logs/`. Прямой `echo` только там, где вывод не должен попасть в лог.

## 4. Карта репозитория

```
scripts/lib/common.sh   — пути, TV_HOST/TV_PORT, log/warn/err, require_cmd,
                          ensure_adb_connected, обёртки adb_shell/adb_cmd
scripts/00-prepare.sh   — проверка adb, подключение, сводка о ТВ, запись .tv-host
scripts/01-backup.sh    — бэкап списков пакетов в backup/ (основа отката)
scripts/02-debloat.sh   — отключение пакетов по debloat.txt, DRY_RUN, сводка
scripts/03-flauncher.sh — поиск/скачивание APK, установка, назначение home
scripts/04-background.sh — запрет работы в фоне (appops) по background.txt;
                          исходные режимы → backup/appops-before.txt
scripts/05-components.sh — отключение отдельных компонентов по components.txt;
                          исходные состояния → backup/components-before.txt
scripts/06-settings.sh  — системные настройки по settings.txt, ТОЛЬКО ключи из ALLOWED;
                          исходные значения → backup/settings-before.txt
scripts/07-theme.sh     — тема лаунчера CleanYourTV через его content-провайдер; --reset
scripts/99-restore.sh   — pm enable всего отключённого; REMOVE_FLAUNCHER=1
packages/debloat.txt    — что отключаем; группы от безопасных к рискованным,
                          каждая строка с комментарием «что это и чем грозит»
packages/background.txt — кому запретить фон, НЕ отключая (иконка остаётся)
packages/components.txt — «пакет/компонент»: какие части приложений отключить
packages/settings.txt   — «раздел ключ значение» для 06 (сейчас анимации 0.5×)
themes/glass-mitv/       — наша тема (glass из CYT + наши приложения в нижнем ряду)
packages/keep.txt       — стоп-лист; 02 читает его и при совпадении не делает ничего
scripts/08-vitrina.sh   — ставит «Витрину» (launcher/), передаёт ей настройки
                          (ряд, город); SET_HOME=1 — сделать домом
launcher/               — исходники лаунчера «Витрина» (Java, без зависимостей),
                          README.md — что на экране, откуда данные, сборка
mibox-s2/               — подпроект приставки TV Box S 2: обёртки scripts/ (00, 01,
                          02, 03, 07, 08, 99) с DEVICE_DIR=mibox-s2, свои packages/,
                          README.md для владельца, CLAUDE.md с журналом
```

Порядок запуска у пользователя: `00 → 01 → DRY_RUN=1 02 → 02 → 03`, и только
после того, как FLauncher заработал — раскомментировать `com.mitv.tvhome`
в `debloat.txt` и прогнать `02` повторно.

## 6. Как вести работу

- **Проверяй на железе, не на предположениях.** Имена пакетов у разных
  прошивок Mi TV отличаются. Не добавляй пакет в `debloat.txt`, не увидев его
  в выводе `pm list packages` с реального ТВ; если добавляешь по внешнему
  источнику — помечай комментарием `# не проверено`.
- **Любая правка — отдельный коммит с понятным сообщением на русском**, пуш
  сразу после правки.
- **Перед каждым push** проверяй дифф на личные данные: в репо не должны
  утечь IP/MAC телевизора, имена хостов, логины, почта и имя владельца.
  Репозиторий ПУБЛИЧНЫЙ с 2026-10-25. Проверка (должно быть 0):
  `git diff --cached | grep -cE '192\.168\.[0-9]+\.[0-9]+|([0-9a-fA-F]{2}:){5}|@gmail|gho_|ghp_'`
  (пример `192.168.0.42` в подсказках допустим). Коммиты — только с адресом
  `281053242+mikkure-coder@users.noreply.github.com` (задан в git config репо;
  на новой машине задать заново). Агента `pii-scrubber` в окружении нет.
- **Нечего отлаживать вслепую.** Если шаг требует реального ТВ, а его нет под
  рукой — не выдумывай результат. Опиши, какую команду должен выполнить
  владелец, и какой вывод тебе нужен обратно.
- **Shell-качество** (чисто на 2026-10-25, shellcheck 0.10.0;
  запуск `shellcheck -x -P scripts:scripts/lib …`): `shellcheck scripts/*.sh scripts/lib/*.sh` должен быть
  чистым; кавычить переменные всегда (`"$pkg"`), `[[ ]]` вместо `[ ]`.
- Спросили мнение («а что если…») — отвечай оценкой и останавливайся;
  код трогать после явного «делай».
