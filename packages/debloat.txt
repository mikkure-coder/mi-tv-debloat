# =============================================================================
# СПИСОК ПАКЕТОВ Mi TV 4S ДЛЯ ОТКЛЮЧЕНИЯ (pm disable-user --user 0)
# =============================================================================
#
# Как работает скрипт 02-debloat.sh:
#   - читает этот файл построчно;
#   - пустые строки и строки, начинающиеся с «#», игнорируются
#     (значит, чтобы оставить какой-то пакет в покое — поставь «#» в начале);
#   - для каждого непустого имени пакета вызывает:
#     adb shell pm disable-user --user 0 <имя>
#
# ВАЖНО:
#   - pm disable-user НЕ удаляет пакет, а «замораживает» его.
#     В любой момент можно откатиться скриптом 99-restore.sh (pm enable).
#   - Фабричный сброс ТВ вернёт всё в исходное состояние.
#   - Пакеты ниже разбиты по группам. Начни с «безопасной» группы,
#     прогони ТВ сутки — если ничего важного не отвалилось, расширяй.
#
# ПРОВЕРЕННЫЕ ПАКЕТЫ Xiaomi Mi TV 4S (Android TV 9/10, PatchWall):
# =============================================================================


# ---- БЕЗОПАСНАЯ ГРУППА (мусор без рисков) ---------------------------------
# Телеметрия, водяные знаки, реклама в PatchWall — отключение ничего не ломает.

com.xiaomi.mitv.anydoor
com.xiaomi.mitv.watermark
com.xiaomi.mitv.statisticsservice
com.xiaomi.mitv.systemui.cardaddition
com.xiaomi.mitv.feedback


# ---- МАГАЗИН И ПЛАТЕЖИ Xiaomi ---------------------------------------------
# Это отдельный магазин Xiaomi, НЕ Google Play. Если ставишь приложения
# только через Google Play / sideload — можно смело выключать.

com.xiaomi.mitv.appstore
com.xiaomi.mitv.payment
com.xiaomi.mitv.account


# ---- ПРОПРИЕТАРНЫЕ УТИЛИТЫ Xiaomi -----------------------------------------
# Файловый менеджер Mi, Mi Share (аналог AirDrop), «ассистент».
# Если пользуешься встроенным файловым менеджером — закомментируй handyman.

com.xiaomi.mitv.handyman
com.xiaomi.mitv.smartshare
com.mitv.tvhelper


# ---- ВСТРОЕННЫЙ ВИДЕОПЛЕЕР ------------------------------------------------
# Mi Video Player — редко нужен, обычно смотрят через стримы.
# Если втыкаешь флэшку с фильмом и хочешь встроенный плеер — оставь.

com.mitv.videoplayer


# ---- PATCHWALL — САМ LAUNCHER ---------------------------------------------
# ⚠️  ВНИМАНИЕ: отключать com.mitv.tvhome нужно ПОСЛЕ установки FLauncher
# (скрипт 03-flauncher.sh) ИЛИ если на устройстве гарантированно есть
# стандартный Android TV Launcher (com.google.android.tvlauncher).
#
# Скрипт 02-debloat.sh сам проверяет это и ОТКАЖЕТСЯ отключать PatchWall,
# если на ТВ нет другого home-launcher — чтобы не остаться без домашнего
# экрана. По умолчанию строка ниже закомментирована: раскомментируй её
# ТОЛЬКО после того, как 03-flauncher.sh отработал успешно.

#com.mitv.tvhome


# ---- OTA-ОБНОВЛЕНИЯ -------------------------------------------------------
# ⚠️  Решение за тобой:
#   - Если отключить, прошивка больше не обновится — зато вернувшиеся
#     при OTA пакеты Xiaomi тоже не прилетят.
#   - Если оставить (= держать строки закомментированными), прошивка будет
#     обновляться, но после каждого обновления, возможно, придётся снова
#     прогнать 02-debloat.sh.
# По умолчанию ОСТАВЛЕНО (строки закомментированы) — безопаснее для патчей.

#com.xiaomi.mitv.osupdater
#com.xiaomi.mitv.updatecenter


# ---- ТВ-ВХОД (АНТЕННА/HDMI) -----------------------------------------------
# ⚠️  Если пользуешься встроенным HDMI/антенной — НЕ ТРОГАЙ эту строку.
# Включать только если ТВ подключён исключительно к стримам/приставке
# по сети и физические входы не нужны.

#com.xiaomi.mitv.tvinput
