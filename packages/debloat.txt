# =============================================================================
# СПИСОК ПАКЕТОВ Mi TV 4S ДЛЯ ОТКЛЮЧЕНИЯ (pm disable-user --user 0)
# =============================================================================
#
# Как работает скрипт 02-debloat.sh:
#   - читает этот файл построчно;
#   - пустые строки и строки, начинающиеся с «#», игнорируются
#     (значит, чтобы оставить какой-то пакет в покое — поставь «#» в начале);
#   - для каждого непустого имени пакета вызывает:
#     adb shell pm disable-user --user 0 <имя>
#
# ВАЖНО:
#   - pm disable-user НЕ удаляет пакет, а «замораживает» его.
#     В любой момент можно откатиться скриптом 99-restore.sh (pm enable).
#   - Фабричный сброс ТВ вернёт всё в исходное состояние.
#   - Пакеты ниже разбиты по группам. Начни с «безопасной» группы,
#     прогони ТВ сутки — если ничего важного не отвалилось, расширяй.
#
# ПАКЕТЫ СВЕРЕНЫ С ЖИВЫМ Mi TV 4S (MiTV-MSSP1, Android 9), 2026-10-24.
# Каждое имя ниже реально есть на этом ТВ (pm list packages).
# Пометка «не проверено» значит: пакет на ТВ есть, но что именно сломается
# или не сломается после отключения — ещё не проверяли на практике.
# Прежний список (anydoor, watermark, appstore и т.п.) удалён: из его
# 16 имён на этом ТВ нашлось только com.mitv.videoplayer.
# =============================================================================
