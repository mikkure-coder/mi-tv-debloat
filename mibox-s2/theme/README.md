# Тема лаунчера CleanYourTV для приставки Xiaomi TV Box S 2

Копия нашей темы телевизора [`themes/glass-mitv`](../../themes/glass-mitv/README.md):
тёмный фон, стеклянная панель, как у Apple TV. Основа — тема `themes/glass`
из https://github.com/Gathin23/cleanyourtv (коммит `204143007f0b`, лицензия MIT,
текст в `LICENSE-cleanyourtv` рядом). `wallpaper.jpg` взят оттуда без изменений.

Отличается только `dock_apps` — нижний ряд из приложений приставки
(2026-10-25). Первые три — по времени просмотра на самой приставке (Okko,
VK Видео, Кинопоиск), остальные — как на телевизоре (Rutube, KION, YouTube).
У Rutube на приставке другое имя пакета: `ru.rutube.app`, а не `ru.rutube.app.tv`.

Управление иконками — как на телевизоре:
- удержание OK на плитке — меню «Переместить / Убрать с главного / О приложении»;
- в конце главного экрана — библиотека всех приложений; OK ставит или снимает
  галочку «на главном экране».

Ставится: `./mibox-s2/scripts/07-theme.sh` (по умолчанию эта тема).
Откат: `./mibox-s2/scripts/07-theme.sh --reset` или `./mibox-s2/scripts/99-restore.sh`.
