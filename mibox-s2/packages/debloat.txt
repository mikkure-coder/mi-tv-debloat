# =============================================================================
# СПИСОК ПАКЕТОВ ПРИСТАВКИ Xiaomi TV Box S 2 ДЛЯ ОТКЛЮЧЕНИЯ
# (pm disable-user --user 0; читает ./mibox-s2/scripts/02-debloat.sh)
# =============================================================================
#
# Как читать файл:
#   - строка с именем пакета — будет отключён;
#   - строка, начинающаяся с «#», — пропускается (так пакет оставляют в покое);
#   - pm disable-user НЕ удаляет пакет, а «замораживает». Вернуть всё —
#     ./mibox-s2/scripts/99-restore.sh, вернуть один — pm enable <имя>.
#
# ОТКУДА СПИСОК: CleanYourTV, examples/xiaomi-mi-box-s-2nd-gen — там каждую
# строку отключали на этой же модели (MiTV-AFKR0, jaws) и проверяли
# перезагрузкой. НО там была прошивка Google TV 11 (сборка RTT0…), а на нашей
# приставке сборка Android 14 (UKG3.250107.001). Поэтому каждая строка помечена
# «не проверено»: имена и последствия на нашей прошивке ещё предстоит сверить
# с бэкапом (01) и перезагрузкой. Пометку снимаем по факту, как у телевизора.
#
# Порядок работы: сначала DRY_RUN=1, потом группы 1–2, перезагрузка, пара дней
# жизни — и только потом остальное.
# =============================================================================
