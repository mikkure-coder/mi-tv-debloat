# Приставка Xiaomi TV Box S 2 — подпроект

Та же очистка, что у телевизора, но для приставки **Xiaomi TV Box S
2-го поколения** (модель MiTV-AFKR0, Google TV): отключить рекламу,
телеметрию и лишние приложения, потом поставить чистый домашний экран.

Скрипты общие с телевизором — лежат в `scripts/` в корне репозитория.
В этой папке только то, что своё у приставки:

```
mibox-s2/scripts/   — обёртки: запускают общие скрипты для приставки
mibox-s2/packages/  — что отключаем (debloat.txt) и что трогать нельзя (keep.txt)
mibox-s2/backup/    — бэкапы приставки (в git не попадают)
mibox-s2/logs/      — логи запусков (в git не попадают)
mibox-s2/CLAUDE.md  — заметки для агента: что известно и что проверено
```

**Состояние на 2026-10-25:** отключены телеметрия и реклама Xiaomi и Google
(9 пакетов). Домашний экран — лаунчер CleanYourTV в стиле Apple TV; Google TV
и мастер настройки отключены. После перезагрузки всё держится, Wi-Fi на месте.
Play Игры и печать отключить нельзя: система включает их обратно.

## Подготовка приставки (один раз)

1. **Режим разработчика.** На приставке: Настройки → Система → Об устройстве.
   Наведи на пункт «Сборка ОС Android TV» и нажми OK на пульте 7 раз подряд,
   пока не появится надпись, что ты стал разработчиком.
2. **Отладка.** Настройки → Система → Для разработчиков → включи
   «Отладка по USB». Кабель не нужен: на приставках Android TV этот пункт
   открывает отладку и по сети.
3. **IP приставки.** Настройки → Сеть и Интернет → твоя сеть Wi-Fi → IP-адрес.
4. **Первое подключение.** Когда запустишь `00`, на экране телевизора
   появится вопрос «Разрешить отладку?». Отметь «Всегда разрешать с этого
   компьютера» и нажми OK.

## Как пользоваться

Команды запускаются из корня репозитория `mi-tv-debloat`:

```bash
# 0. Подключение и сводка о приставке (сохраняет IP в mibox-s2/.tv-host)
./mibox-s2/scripts/00-prepare.sh

# 1. Бэкап списков пакетов — без него нет отката
./mibox-s2/scripts/01-backup.sh

# 2. Отключение по списку mibox-s2/packages/debloat.txt
DRY_RUN=1 ./mibox-s2/scripts/02-debloat.sh   # сначала только показать
./mibox-s2/scripts/02-debloat.sh             # потом по-настоящему

# 3. Новый домашний экран (лаунчер CleanYourTV из общей папки apks/)
./mibox-s2/scripts/03-flauncher.sh
```

После каждого шага, который что-то меняет, — перезагрузка приставки
и проверка, что всё держится.

## Чем приставка отличается от телевизора

- **Google TV вместо Android TV.** Домашний экран здесь другой
  (`com.google.android.apps.tv.launcherx`), и его отключение выключает кнопки
  Netflix, YouTube и «Приложения» на пульте.
- **Мастер первой настройки держит домашний экран и Wi-Fi.** У других людей
  с этой моделью новый лаунчер стал домом, только когда отключили ещё и
  мастер настройки. После этого Wi-Fi пропадал на 20 секунд и приставка один раз
  просила пароль заново. Сейчас мастер в стоп-листе, и отключать его или нет —
  твоё решение, когда дойдём до этого шага.
- **Прошивка новее, чем у всех, на чей опыт опираемся.** У них был Google TV 11,
  у нас Android 14. Поэтому каждый пакет в списке помечен «не проверено».

## Откат

```bash
./mibox-s2/scripts/99-restore.sh                     # включить всё отключённое
REMOVE_LAUNCHER=1 ./mibox-s2/scripts/99-restore.sh   # и удалить новый лаунчер
```

**Перед сбросом к заводским настройкам** сначала запусти откат. Так советуют
оба проекта, которые уже чистили эту модель (CleanYourTV и BoxClean). Почему
именно — они не пишут, а мы пока не проверяли.
