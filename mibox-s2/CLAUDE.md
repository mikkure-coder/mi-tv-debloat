# CLAUDE.md — подпроект mibox-s2 (приставка Xiaomi TV Box S 2)

Дополнение к корневому [`CLAUDE.md`](../CLAUDE.md). **Все его правила
действуют здесь полностью**: границы проекта (раздел 2), инварианты кода
(раздел 3), «проверяй на железе», коммит на каждую правку, проверка диффа
на личные данные перед push. Этот файл добавляет только то, что своё
у приставки.

## 1. Устройство

Xiaomi TV Box S 2nd Gen: модель `MiTV-AFKR0`, кодовое имя `jaws`,
чип Amlogic S905X4, 2 ГБ ОЗУ, Google TV. Без HDMI-входов и тюнера.

Что известно на 2026-10-25 без ADB (через Cast-API приставки, порт 8008):
сборка `UKG3.250107.001`. По BetaWiki это **бета Android 14** для этой модели,
разосланная через OTA-серверы Google 2025-03-03, с типом сборки `userdebug`.
Тип сборки проверить через `getprop ro.build.type` в `00`/`01`.
Даже если `adb root` доступен — **не использовать**: root запрещён разделом 2.

## 2. Как устроен подпроект

Обёртки в `mibox-s2/scripts/` задают `DEVICE_DIR=mibox-s2` и запускают
одноимённый общий скрипт из `scripts/`. Через `DEVICE_DIR` общий код берёт
`packages/`, `backup/`, `logs/` и `.tv-host` приставки (см. `lib/common.sh`).
Общими остаются `apks/` (лаунчер) и `themes/`.

Правило: **своё у приставки — только данные** (списки, заметки). Если для
приставки нужно другое поведение скрипта, правится общий скрипт так, чтобы
телевизор не сломался, а не копируется скрипт в подпроект. Обёртки есть
для 00, 01, 02, 03, 07, 99. Обёртка 07 нужна пока только для `--reset`
(его вызывает 99): своей темы у приставки нет, а тема по умолчанию
`glass-mitv` собрана под телевизор. 04–06 добавлять, когда до них дойдёт
дело, вместе с нужными файлами в `packages/`.

## 3. Чужой опыт с этой моделью (не наш, проверено на Google TV 11)

Источник — CleanYourTV, `examples/xiaomi-mi-box-s-2nd-gen/debloat.txt`
(MIT; сборки `RTT0.211222.001/772` и `.737`, проверено 2026-10-19).
Повторено в BoxClean (`lists/`, Apache-2.0, тот же автор списка).

- ADB по сети на 5555 открылся сразу после «Отладки по USB», без пар-кода.
  На Android 14 может понадобиться «Беспроводная отладка» с `adb pair` и
  другим портом — тогда `TV_PORT=<порт>` при запуске.
- Претенденты на HOME на заводской прошивке: `launcherx` (приоритет 2),
  `setupwraith/.RecoveryActivity` (приоритет 1), `FallbackHome` из Настроек.
- Отключение одного `launcherx` отдаёт дом `RecoveryActivity` мастера.
  `set-home-activity` отвечает Success, но не действует, пока не отключён
  и `setupwraith`. Поэтому `02` с 2026-10-25 не считает `setupwraith`
  запасным домом.
- После отключения `setupwraith` Wi-Fi пропал примерно на 20 с, приставка
  один раз спросила пароль; дальше сеть держалась после перезагрузки.
  Владелец сети в `dumpsys wifi` сменился с `setupwraith` на
  `com.android.tv.settings`. BoxClean отказывается отключать мастер, пока сеть
  принадлежит ему, и советует сначала забыть сеть и подключиться заново.
- Без `launcherx` кнопки пульта Netflix, YouTube, Prime Video, «Приложения»
  ничего не делают. Пульт «Xiaomi RC» шлёт Netflix как 193 (`BUTTON_6`),
  YouTube как 190 (`BUTTON_3`), Prime как 194 (`BUTTON_7`); лаунчер
  CleanYourTV умеет назначать на них приложения (`app_keys`).
- Остались рабочими после всего: Wi-Fi, флешки, Google Home, пульт с
  телефона, Chromecast, Ассистент.
- Сопряжение пульта держит `com.google.android.tv.remote.service` — он в
  стоп-листе.

## 4. Открытые решения (за владельцем)

1. **`setupwraith`.** Он в `is_core_pkg` (общий запрет, из-за Wi-Fi и #884)
   и в `keep.txt`. Без его отключения CleanYourTV, вероятно, не станет домом.
   Варианты, когда дойдём: оставить Google TV домом и только чистить;
   отключить мастер для этой приставки (нужна правка общего запрета только для
   `DEVICE_DIR` приставки и проверка владельца Wi-Fi до отключения);
   сначала проверить на нашей прошивке, может ли лаунчер стать домом иначе.
   Решение не принимать за владельца и не ослаблять запрет для телевизора.
2. **Группы 3–4 в `debloat.txt`** (предустановленные приложения, обновления
   прошивки) — по желанию владельца.

## 5. Журнал проверки на железе

- 2026-10-25: приставка найдена в домашней сети через Cast-API, модель и
  сборка выше. ADB (5555) закрыт — отладка ещё не включена.

## 6. Очередь

1. Владелец включает «Отладку по USB». Прогон `00` и `01`: Android, SDK,
   `ro.build.type`, домашний экран, полный список пакетов.
2. Сверить `debloat.txt` и `keep.txt` с бэкапом: убрать отсутствующие имена,
   дописать полные имена `com.droidlogic.*` в стоп-лист, снять «не проверено»
   там, где имя подтвердилось.
3. `DRY_RUN=1 02`, потом группы 1–2, перезагрузка, проверка, что держится.
4. `03`: установка лаунчера, ручной запуск, проверка Home. Затем решение по
   `setupwraith` (раздел 4).
