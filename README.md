# mi-tv-debloat

Набор скриптов для «очистки» телевизора **Xiaomi Mi TV 4S 50" (Android TV 9)**:
отключение рекламы, телеметрии и предустановленного мусора + замена домашнего
экрана на открытый лаунчер в стиле Apple TV
([CleanYourTV](https://github.com/Gathin23/cleanyourtv), собирается из исходников)
или [FLauncher](https://gitlab.com/flauncher/flauncher).

> ⚠️ **Проверено только на одном телевизоре:** Mi TV 4S, модель MiTV-MSSP1
> (`nino`), прошивка PI.5925, 2026-10. На других моделях и прошивках имена
> пакетов и поведение отличаются — списки в `packages/` сверяйте со своим ТВ
> (`01-backup.sh` снимает реальный список) и начинайте с `DRY_RUN=1`.
> Используете на свой риск; лицензия MIT, без гарантий. Что пробовали и что
> не сработало на этом ТВ — в `CLAUDE.md`, раздел 5.

Scope — только дебло́ат и смена launcher'а. Никаких root-ROM, разблокировок
загрузчика и прочих необратимых вещей здесь нет. Всё, что делают скрипты,
обратимо через `99-restore.sh` или фабричный сброс.

## Что происходит под капотом

Скрипты работают через **ADB по сети**:
- не удаляют пакеты (`pm uninstall`), а «замораживают» их через
  `pm disable-user --user 0 <pkg>` — любой пакет возвращается одной командой
  `pm enable`;
- не требуют root и разблокировки загрузчика;
- хранят резервную копию списка установленных пакетов в `backup/` до начала работы.

## Требования

На управляющей машине (ноутбуке):
- `adb` (пакет `android-tools-adb` на Debian/Ubuntu, `android-tools` на Fedora,
  `android-platform-tools` в Homebrew);
- `bash` 4+, `curl` (для автоматического скачивания APK FLauncher).

На телевизоре:
- включена **«Отладка по сети»** (она же «Network ADB»):
  `Настройки → Настройки устройства → Об устройстве → Сборка` — тапнуть 7 раз,
  потом `Настройки → Настройки устройства → Для разработчиков → Отладка по сети`;
- известен IP ТВ в локальной сети (`Настройки → Сеть → Информация`);
- ноут и ТВ в одной Wi-Fi/LAN сети.

## Как пользоваться

```bash
git clone https://github.com/mikkure-coder/mi-tv-debloat.git
cd mi-tv-debloat

# 0. Подключение + сводка о ТВ (сохраняет IP в .tv-host)
./scripts/00-prepare.sh
# или без интерактивного ввода:
# TV_HOST=192.168.0.42 ./scripts/00-prepare.sh

# 1. Полный бэкап списков пакетов (нужен для отката)
./scripts/01-backup.sh

# 2. Отключение мусора по списку packages/debloat.txt
# Сначала «сухой прогон» — ничего не меняет, только печатает, что сделает:
DRY_RUN=1 ./scripts/02-debloat.sh
# Потом боевой запуск:
./scripts/02-debloat.sh

# 2½. Запрет работы в фоне без отключения (иконка остаётся) —
#      по списку packages/background.txt
DRY_RUN=1 ./scripts/04-background.sh
./scripts/04-background.sh

# 2¾. Отключение отдельных частей приложений (например, автозапуска при
#      загрузке ТВ) — по списку packages/components.txt, иконка остаётся
DRY_RUN=1 ./scripts/05-components.sh
./scripts/05-components.sh

# 2⅞. Системные настройки (сейчас — анимации в 2 раза быстрее) —
#      по списку packages/settings.txt, только разрешённые ключи
DRY_RUN=1 ./scripts/06-settings.sh
./scripts/06-settings.sh

# 3. Установка лаунчера (APK из apks/, см. ниже) и назначение домашним экраном
DRY_RUN=1 ./scripts/03-flauncher.sh
./scripts/03-flauncher.sh
```

После шага 3: нажми Home на пульте ТВ. Если появится выбор — выбери новый
лаунчер и «Всегда». На Mi TV 4S выбора не будет: у Google-лаунчера приоритет
выше, и Android всегда открывает его. Тогда, убедившись, что новый лаунчер
открывается из списка приложений, отключи Google-лаунчер строкой в
`packages/debloat.txt` через `02` — так и сделано у нас (2026-10-25).
Вернуть: `./scripts/99-restore.sh`.

### Тема лаунчера CleanYourTV

```bash
DRY_RUN=1 ./scripts/07-theme.sh       # показать, что будет сделано
./scripts/07-theme.sh                 # тема themes/glass-mitv (вид как у Apple TV)
./scripts/07-theme.sh --reset         # вернуть встроенный вид
```

Тема — файлы настроек и обои внутри данных самого лаунчера; систему не трогает.
Порядок приложений в нижнем ряду — `dock_apps` в `themes/glass-mitv/config.json`.

### Лаунчер в стиле Apple TV (CleanYourTV): сборка из исходников

Готового APK у проекта нет, собираем на ноутбуке. Проверено 2026-10-25 на
Ubuntu 24.04, коммит `204143007f0b`, сборка ~1 минута.

```bash
# Один раз: Java 17 и Android SDK
sudo apt install -y openjdk-17-jdk-headless unzip
# Инструменты Android с dl.google.com распаковать в ~/Android/Sdk/cmdline-tools/latest, затем:
~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=$HOME/Android/Sdk --licenses
~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=$HOME/Android/Sdk \
    --install "platforms;android-34" "build-tools;34.0.0" "platform-tools"

# Сборка с конкретного просмотренного коммита
git clone https://github.com/Gathin23/cleanyourtv.git && cd cleanyourtv
git checkout 204143007f0bebfb14d6ef001a32e5836b1c90b5
cd launcher && ANDROID_HOME=$HOME/Android/Sdk ./gradlew --no-daemon assembleRelease
cp app/build/outputs/apk/release/app-release.apk <путь к mi-tv-debloat>/apks/
```

Их `build-and-install.sh` **не запускать**: он отключает Google-лаунчер и
выдаёт лаунчеру лишние права. Ставим нашим `03`. Подробности — CLAUDE.md, раздел 2.

## Откат

```bash
DRY_RUN=1 ./scripts/99-restore.sh          # показать, что будет включено
./scripts/99-restore.sh                    # включить всё, что отключено после бэкапа
REMOVE_LAUNCHER=1 ./scripts/99-restore.sh  # ещё и удалить новый лаунчер
```

99 сравнивает, что отключено сейчас, с самым ранним бэкапом из `backup/`,
и включает всё лишнее — даже если строку в `debloat.txt` уже закомментировали.
Домашний экран возвращается тот, что записан в бэкапе.

**Без ноутбука**: Настройки → Приложения → Показать системные приложения →
нужный пакет → Включить. Пока работают меню и пульт, так можно вернуть любой
отключённый пакет.

Если что-то пошло совсем не так — фабричный сброс в
`Настройки → Настройки устройства → Сброс` вернёт ТВ в заводское состояние,
но сотрёт приложения и аккаунты. Это последний вариант, не первый.

## Как не «окирпичить» ТВ

Собрано по реальным случаям в проекте CleanYourTV (issues #884, #795, #62,
#962, docs/TROUBLESHOOTING.md) и проверено на нашем Mi TV 4S 2026-10-24.

1. **Не отключать ядро Android.** На Mi TV Stick (#884) отключили
   `permissioncontroller`, `packageinstaller`, `ext.services` и др. — приставка
   перестала загружаться навсегда. `02-debloat.sh` теперь сам отказывается
   работать, если такой пакет или пакет из `keep.txt` попал в `debloat.txt`.
2. **Не отключать `com.google.android.tungsten.setupwraith`.** На нашем ТВ
   ему принадлежит текущая Wi-Fi-сеть: Android удалит её вместе с отключением,
   ТВ потеряет сеть, а мы — ADB. Он в `keep.txt` и в жёстком запрете.
3. **Не оставлять ТВ без домашнего экрана.** Это ловит предохранитель в `02`;
   `03` проверяет, что по Home *на деле* открылся FLauncher — ответ
   `Success` от системы бывает ложным.
4. **Маленькими порциями.** 2–6 пакетов → перезагрузка → посмотреть на экран
   → пожить с ТВ → следующая порция. Не всё сразу.
5. **Не перезагружать ТВ, если что-то уже выглядит странно** (пустой или
   серый экран, непривычное меню). Сначала `./scripts/99-restore.sh`, потом
   перезагрузка.
6. **Не выключать «Отладку по USB».** На этом ТВ ADB по сети работает только
   через неё — это наш единственный вход.
7. **Если ТВ завис на загрузке**: подождать 10 минут; с ноутбука несколько
   минут подряд пробовать `adb connect <IP>:5555` — сеть иногда поднимается
   уже после логотипа; если подключилось — `./scripts/99-restore.sh`.

## Структура

```
mi-tv-debloat/
├── scripts/
│   ├── lib/common.sh        — общие функции (log, require_cmd, adb-подключение)
│   ├── 00-prepare.sh        — проверка adb, подключение, сводка о ТВ
│   ├── 01-backup.sh         — бэкап списков пакетов в backup/
│   ├── 02-debloat.sh        — отключение пакетов по debloat.txt
│   ├── 03-flauncher.sh      — установка FLauncher и назначение его home
│   └── 99-restore.sh        — откат: включить всё обратно
├── packages/
│   ├── debloat.txt          — что отключаем (с комментариями по каждому пакету)
│   └── keep.txt             — что НЕ трогаем (ТВ без них работать перестанет)
├── logs/                    — локальные логи запусков (gitignore)
├── backup/                  — локальные бэкапы списков пакетов (gitignore)
├── apks/                    — скачанный APK FLauncher (gitignore)
├── launcher/                — свой лаунчер «Витрина» (исходники)
└── mibox-s2/                — подпроект: приставка Xiaomi TV Box S 2 (Google TV)
```

## Свой лаунчер «Витрина»

Светлый домашний экран в стиле Apple TV с постерами Кинопоиска, погодой и
курсами — в папке [`launcher/`](launcher/README.md). Ставится скриптом
`08-vitrina.sh`. Сейчас — домашний экран приставки.

## Приставка Xiaomi TV Box S 2

Та же очистка для приставки живёт в отдельной папке [`mibox-s2/`](mibox-s2/README.md):
там свои списки пакетов, бэкапы и порядок запуска. Скрипты общие, их
запускают обёртки из `mibox-s2/scripts/`, например
`./mibox-s2/scripts/00-prepare.sh`.

## Безопасность

- Все скрипты только читают/отключают пакеты, никаких `pm uninstall --user 0`
  и подобных «тихих» удалений: любой шаг обратим.
- `02-debloat.sh` до подключения к ТВ сверяет `debloat.txt` со стоп-листом
  (`keep.txt` + ядро Android) и при совпадении не отключает ничего.
- `02-debloat.sh` не отключает пакет-домашний экран (список берёт у ТВ) и
  PatchWall, если после этого не останется другого дома.
- APK FLauncher берётся только с **F-Droid** (`me.efesser.flauncher`,
  репозиторий `https://gitlab.com/flauncher/flauncher`) — проверяемая сборка
  из открытых исходников. Скачанные APK в репозиторий не коммитятся
  (см. `.gitignore`).
- IP телевизора (`.tv-host`) и логи остаются только локально.
