# mi-tv-debloat

Набор скриптов для «очистки» телевизора **Xiaomi Mi TV 4S 50" (Android TV 9/10)**:
отключение PatchWall, рекламы и предустановленного мусора + установка
альтернативного домашнего экрана **FLauncher** (OSS, без рекламы и трекинга).

Scope — только дебло́ат и смена launcher'а. Никаких root-ROM, разблокировок
загрузчика и прочих необратимых вещей здесь нет. Всё, что делают скрипты,
обратимо через `99-restore.sh` или фабричный сброс.

## Что происходит под капотом

Скрипты работают через **ADB по сети**:
- не удаляют пакеты (`pm uninstall`), а «замораживают» их через
  `pm disable-user --user 0 <pkg>` — любой пакет возвращается одной командой
  `pm enable`;
- не требуют root и разблокировки загрузчика;
- хранят резервную копию списка установленных пакетов в `backup/` до начала работы.

## Требования

На управляющей машине (ноутбуке):
- `adb` (пакет `android-tools-adb` на Debian/Ubuntu, `android-tools` на Fedora,
  `android-platform-tools` в Homebrew);
- `bash` 4+, `curl` (для автоматического скачивания APK FLauncher).

На телевизоре:
- включена **«Отладка по сети»** (она же «Network ADB»):
  `Настройки → Настройки устройства → Об устройстве → Сборка` — тапнуть 7 раз,
  потом `Настройки → Настройки устройства → Для разработчиков → Отладка по сети`;
- известен IP ТВ в локальной сети (`Настройки → Сеть → Информация`);
- ноут и ТВ в одной Wi-Fi/LAN сети.

## Как пользоваться

```bash
git clone https://github.com/mikkure-coder/mi-tv-debloat.git
cd mi-tv-debloat

# 0. Подключение + сводка о ТВ (сохраняет IP в .tv-host)
./scripts/00-prepare.sh
# или без интерактивного ввода:
# TV_HOST=192.168.0.42 ./scripts/00-prepare.sh

# 1. Полный бэкап списков пакетов (нужен для отката)
./scripts/01-backup.sh

# 2. Отключение мусора по списку packages/debloat.txt
# Сначала «сухой прогон» — ничего не меняет, только печатает, что сделает:
DRY_RUN=1 ./scripts/02-debloat.sh
# Потом боевой запуск:
./scripts/02-debloat.sh

# 3. Установка FLauncher и назначение его домашним экраном
./scripts/03-flauncher.sh
```

После шага 3: нажми Home на пульте ТВ, выбери FLauncher, пункт
«Всегда» / «Запомнить выбор». Если всё хорошо — можно
раскомментировать `com.mitv.tvhome` в `packages/debloat.txt` и ещё раз
прогнать `02-debloat.sh`, чтобы окончательно отключить PatchWall.

## Откат

```bash
./scripts/99-restore.sh                    # включить все отключённые пакеты
REMOVE_FLAUNCHER=1 ./scripts/99-restore.sh # ещё и удалить FLauncher
```

Если что-то пошло совсем не так — фабричный сброс в
`Настройки → Настройки устройства → Сброс` вернёт ТВ в заводское состояние.

## Структура

```
mi-tv-debloat/
├── scripts/
│   ├── lib/common.sh        — общие функции (log, require_cmd, adb-подключение)
│   ├── 00-prepare.sh        — проверка adb, подключение, сводка о ТВ
│   ├── 01-backup.sh         — бэкап списков пакетов в backup/
│   ├── 02-debloat.sh        — отключение пакетов по debloat.txt
│   ├── 03-flauncher.sh      — установка FLauncher и назначение его home
│   └── 99-restore.sh        — откат: включить всё обратно
├── packages/
│   ├── debloat.txt          — что отключаем (с комментариями по каждому пакету)
│   └── keep.txt             — что НЕ трогаем (ТВ без них работать перестанет)
├── logs/                    — локальные логи запусков (gitignore)
├── backup/                  — локальные бэкапы списков пакетов (gitignore)
└── apks/                    — скачанный APK FLauncher (gitignore)
```

## Безопасность

- Все скрипты только читают/отключают пакеты, никаких `pm uninstall --user 0`
  и подобных «тихих» удалений: любой шаг обратим.
- `02-debloat.sh` отказывается отключать PatchWall (`com.mitv.tvhome`), если
  на ТВ не найден альтернативный home — чтобы ТВ не остался без домашнего экрана.
- APK FLauncher берётся только с **F-Droid** (`me.efesser.flauncher`,
  репозиторий `https://gitlab.com/flauncher/flauncher`) — проверяемая сборка
  из открытых исходников. Скачанные APK в репозиторий не коммитятся
  (см. `.gitignore`).
- IP телевизора (`.tv-host`) и логи остаются только локально.
