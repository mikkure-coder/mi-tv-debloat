# Kickoff-промпт для агента

Текст ниже скармливается агенту (Claude Code) на той машине, с которой
он будет работать с телевизором — первым сообщением, целиком.
Он задаёт границы проекта и порядок первых шагов; подробности агент
дочитает в [CLAUDE.md](../CLAUDE.md).

---

Задача: продолжить проект mi-tv-debloat — скрипты для «очистки» телевизора
Xiaomi Mi TV 4S 50" (Android TV 9/10, PatchWall) и замены лаунчера на FLauncher.

1. Склонируй репозиторий и прочитай в нём CLAUDE.md целиком — это инструкция
   по проекту, она главнее твоих привычек:
       git clone git@github.com:mikkure-coder/mi-tv-debloat.git
       cd mi-tv-debloat
   Если SSH-ключа этой машины нет в GitHub — сделай `gh auth login`
   (GitHub.com → SSH → Skip upload → Login with a web browser) и клонируй
   через `gh repo clone mikkure-coder/mi-tv-debloat`. Репозиторий приватный.
   Пароли и токены у меня не спрашивай: всё, что требует ввода секрета,
   я делаю сам в терминале, ты только говоришь, какую команду запустить.

2. Границы проекта. Это НЕ прошивка в прямом смысле. Запрещено: root,
   разблокировка загрузчика, кастомные ROM, fastboot flash, recovery,
   `pm uninstall` и любое необратимое удаление пакетов. Только
   `pm disable-user --user 0`, откатываемое через `pm enable`.
   Любое действие, которое ты добавляешь в проект, должно иметь ответ на
   вопрос «как это откатить» — нет ответа, значит в проект не входит.
   Пакеты из packages/keep.txt не трогать ни при каких условиях.

3. Состояние: репозиторий — скелет, на живом телевизоре ни разу не
   запускался. Поэтому приоритет не новые фичи, а первый реальный прогон.
   Порядок работы — раздел 5 в CLAUDE.md:
     а) `./scripts/00-prepare.sh` и `./scripts/01-backup.sh` на живом ТВ,
        снять реальный список пакетов;
     б) сверить его с packages/debloat.txt: какие имена не совпали, чего
        не хватает, что лишнее — и поправить файл по факту, а не по статьям
        из интернета. Непроверенное помечай комментарием `# не проверено`;
     в) проверить, что `./scripts/99-restore.sh` реально откатывает — ДО
        того, как что-то рискованное будет отключено;
     г) прогнать `DRY_RUN=1 ./scripts/02-debloat.sh`, показать мне, что он
        собирается сделать, и только после моего «делай» — боевой запуск
        по безопасной группе;
     д) `03-flauncher.sh` и отключение PatchWall — в последнюю очередь.

4. Что нужно от меня для старта: IP телевизора в локальной сети
   (Настройки → Сеть → Информация) и включённая «Отладка по сети»
   (Настройки → Настройки устройства → Об устройстве → Сборка, тапнуть 7 раз,
   затем Для разработчиков → Отладка по сети). Ноут и ТВ в одной сети.
   Первое подключение ТВ переспросит на экране — подтверждать буду я пультом.

5. Как со мной разговаривать. Я не программист: объясняй механизм команды и
   разбирай её вывод, а не давай копипасту. Если я спрашиваю «а что если
   сделать X?» — это запрос мнения, оцени и остановись, код не трогай до
   явного «делай». Не выдумывай результат команды, которую не выполнял.

6. Правила коммитов: отдельный коммит на каждую смысловую правку, сообщение
   на русском, push сразу после коммита. В репозиторий не должны попадать
   IP и MAC телевизора, логи прогонов, бэкапы и *.apk — всё это уже в
   .gitignore, проверяй дифф перед push.

Начни с клона и чтения CLAUDE.md, потом скажи, что тебе нужно от меня для
первого прогона.
